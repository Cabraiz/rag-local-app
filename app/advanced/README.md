# Agentes e avaliações avançadas

Este laboratório é separado do fluxo normal de consulta. Não está ligado a todas as perguntas e não habilita modelos pagos ou ferramentas de escrita.

| Pasta | Responsabilidade |
| --- | --- |
| `models` | Modelo gratuito restrito, orçamento e cancelamento |
| `tasks` | DeepAgents, ferramentas permitidas, checkpoints e validação do relatório |
| `evaluation` | DeepEval, judge e conjunto de calibração |
| `checks` | Regressões determinísticas de retries e limites |
| `dependencies` | Locks, compilação e verificação das dependências |
| `containers` | Dockerfile deste laboratório |

O [guia da aplicação](../README.md) mostra como localizar ferramentas e acompanhar a fila. Executar o judge ou uma tarefa real pode consumir a cota gratuita; verificar dependências não é prova de qualidade das respostas.
