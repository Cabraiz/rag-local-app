// Cliente > Gateway: 
// Gateway > Seguranca:

// Seguranca > Invalido: Nao
// Dedup > Reserva: Novo

// Reserva > Capacidade: 
// Capacidade > Recusa: Nao
// Capacidade > Ledger: Sim; reserva e pedido na mesma transacao
// Ledger > Recibo: Commit duravel confirmado
// Ledger > Dispatcher: Outbox commitada
// Dispatcher > Broker: Confirmar publicacao antes de marcar enviada
// Broker > Worker: Entrega at-least-once
// Worker > Etapa: Adquirir lease/CAS; validar deadline antes de executar
// Etapa > Orquestrador: Iniciar ou retry valido
// Etapa > Redelivery: Terminal ja commitado
// Orquestrador > Busca: 
// Busca > Analise: 
// Analise > Evidencia: 
// Evidencia > PoliticaResposta: Sim
// Evidencia > Abstencao: Nao ou conflito
// PoliticaResposta > Compositor: Sim; escopo somente leitura
// PoliticaResposta > Abstencao: Nao; POLICY_RESTRICTED sem recomendacao factual
// PoliticaResposta > Retry: Indisponivel ou timeout; fail closed; retry com teto e deadline
// Compositor > Verificador: 
// Verificador > Autorizacao: Passou; factual ou template validado
// Verificador > ModoFalha: Falhou
// ModoFalha > Tentativa: Factual

// Autorizacao > Bloqueio: Nao; negacao confirmada
