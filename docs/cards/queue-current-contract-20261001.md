# Revalidacao da fila no contrato atual

Pedido: executar toda a fila e bugs, sem tratar comprovantes antigos como atuais.

Primeira frente: ingestao aditiva de TXT, Markdown e PDF, preservando fontes e
originais anteriores. Bruno publica; Ana consulta e nao publica. A geracao
esperada e obrigatoria: conflito nao promove corpus. Revogar uma versao nao
revoga implicitamente outras; revogar a fonte bloqueia todas.

Proibido: reabrir rotas de substituicao integral, adicionar identidades de teste
ao produto, desligar o laboratorio em 8840, apagar volumes, usar cloud paga,
ajustar oraculos reservados para passar ou chamar uma simulacao de prova real.

Menor prova: duas rodadas HTTP com arquivos sinteticos em projeto Compose
isolado, PostgreSQL e Qdrant reais, verificando SHA dos bytes baixados,
preservacao, CAS, permissao, revogacao, rejeicoes de parser e sobrevivencia ao
restart apenas do API de QA. Fontes congeladas e imagens registradas.

Gate geral: cada card conserva seus criterios. Vertex pago, identidade real,
carga HTTP e failover nao podem ser aprovados por testes locais substitutos.
Mudancas invalidam recibos dependentes; dois passes sao regressao adversarial
do mesmo autor, nao auditoria independente nem garantia de ausencia de bugs.
